## 音频部分

### ES8311 音频编解码器

| ES8311 引脚 | 功能 | 连接 |
|-----------|------|-----|
| 1 | CCLK | SCL |
| 2 | MCLK | MCLK |
| 3 | PVDD | VDD33 |
| 4 | DVDD | VDD33 |
| 5 | DGND | GND |
| 6 | SCLK/DMIC_SCL | SCLK |
| 7 | ASDOUT | DOUT |
| 8 | LRCK | LRCK |
| 9 | DSDIN | DIN |
| 10 | AGND | GND |
| 11 | AVDD | VDD33 |
| 12 | OUTP | 经 R10 + C40 → NS4150B INP |
| 13 | OUTN | 经 R20 + C42 → NS4150B INN |
| 14 | DACVREF | 接 C38 退耦 → GND |
| 15 | ADCVREF | 接 C37 退耦 → GND |
| 16 | VMID | 接 C36 退耦 → GND |
| 17 | MIC1N | 单端模式下接 GND |
| 18 | MIC1P/DMIC_SDA | 经 C32 隔直 → MIC1 OUT |
| 19 | CDATA | SDA |
| 20 | CE | GND |
| 21 | EP | GND |

引脚3，VDD33，芯片电源输入，与数字电源并联供电

引脚4，VDD33，数字内核电源输入，配套多级电容去耦滤波

引脚11，AVDD（模拟电源）VDD33，模拟电路电源输入，经 L8 磁珠隔离数字电源噪声，配套 C43 去耦

引脚12，OUTP（DAC 模拟输出正端）经 C40 隔直 + R10 限流 → NS4150B INP，DAC 解码后的差分模拟音频正输出，送后级功率放大器

引脚13，OUTN（DAC 模拟输出负端），经 C42 隔直 + R20 限流 → NS4150B INN，DAC 解码后的差分模拟音频负输出，送后级功率放大器

引脚14，DACVREF（DAC 参考电压），接 C37 去耦电容 → GND，DAC 模块参考电压，外接去耦电容稳定基准

引脚15，ADCVREF（ADC 参考电压），接 C36 去耦电容 → GND，ADC 模块参考电压，外接去耦电容稳定基准

引脚16，VMID（共模中点电压），接 C35 去耦电容 → GND，内部共模电压输出，外接大容量电容稳定偏置

引脚17，MIC1N（麦克风输入负端），经 C32 交流接地，单端麦克风输入模式下，负端交流接地，构成单端采集

引脚18，MIC1P / DMIC_SDA（麦克风输入正端 / 数字麦克风数据），经 C26 隔直 → AP2718AT OUT，模拟麦克风信号输入端，接收 MEMS 麦克风的模拟输出

引脚19，CDATA（I2C 配置数据），SDA，I2C 总线数据端，经 R7 (2.2K/1%) 上拉至 VDD33，与主控双向通信

引脚20，CE（芯片使能），GND，芯片使能引脚，接地保持常工作状态

引脚21，EP（裸露散热焊盘），GND，接地，兼顾散热与电气稳定

### NS4150B 功放芯片

| NS4150B 引脚 | 功能 | 连接 |

| 7 | GND | GND |
| 8 | VOP | 接扬声器 VOP，并联 C39/C41 EMI 滤波 |
